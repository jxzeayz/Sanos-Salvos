# Sanos y Salvos

Plataforma web para la localización y recuperación de mascotas perdidas.

## Tecnologías base

- React
- Spring Boot
- PostgreSQL / PostGIS
- RabbitMQ
- MinIO
- Docker Compose
- Git / GitHub

## Estructura inicial

- frontend
- bff-web
- ms-auth
- ms-mascotas
- ms-geolocalizacion
- ms-matching
- ms-notificaciones
- ms-archivos
- ms-auditoria
